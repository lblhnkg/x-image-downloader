# X 图片找图器 v1

这是一个个人低频使用的 iPhone 网页工具。

功能：
- 粘贴 X 博主主页
- 获取时间线中的图片
- 瀑布流浏览
- 点击大图
- 优先通过服务器代理尝试下载 X 原图
- 下载失败时可直接打开原帖
- 不需要 X 密码

数据获取：
- X 官方 API 目前是按使用量计费，并非真正的长期免费方案。
- 本项目 v1 使用开源 x-tweet-fetcher 的 Nitter 路由获取用户时间线；它的项目文档说明时间线依赖 Nitter，并支持分页/时间线抓取。
- Nitter 公共实例可能随时限流或失效，因此 v1 内置多个实例作为故障切换。

部署：
1. 把整个项目上传到 GitHub。
2. 在 Render 创建 Web Service，选择这个仓库。
3. Render 会按 Dockerfile 构建。
4. 部署完成后打开 Render 给出的网址即可。
5. iPhone Safari -> 分享 -> 添加到主屏幕。

注意：
- v1 每次最多读取 200 条帖子；这是为了先把个人低频使用版本跑通。
- 如果某个公共 Nitter 实例被 Cloudflare/反爬拦截，换实例即可。
- 不要把 X 密码、Cookie 或 API Key 放进这个项目。
