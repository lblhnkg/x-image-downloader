X 图片找图器 v3.1

一个面向 iPhone 使用的 X（Twitter）博主图片检索与下载工具。

如果你想找某个 X 博主以前发过的一张图片，不需要再进入博主主页一直向下滑动。

只需要输入博主主页链接，工具会自动获取该用户的帖子图片，并以图片瀑布流的方式集中展示。

⸻

✨ 功能

* 🔗 输入 X 博主主页链接
* 🖼️ 自动获取该博主发布的图片
* 📱 针对 iPhone Safari 使用进行优化
* 🧱 图片瀑布流展示
* 🔍 点击图片查看大图
* ⬇️ 优先尝试获取并下载 X 原图
* 🔗 下载失败时可以直接打开对应 X 原帖
* 🚫 不需要输入 X 账号密码
* 🔄 支持多个数据获取节点进行故障切换
* 🌐 可以部署到云服务器，通过手机浏览器直接访问

⸻

🎯 使用场景

例如你想找某个 X 博主半年前发布的一张图片。

传统方法：

打开 X → 进入博主主页 → 一直向下滑 → 等待加载 → 继续滑 → 找到图片

使用本项目：

输入博主主页 → 等待加载 → 浏览图片 → 点击目标图片 → 下载

尤其适合需要从某个博主大量历史图片中寻找特定图片的情况。

⸻

📱 iPhone 使用

本项目主要按照 iPhone Safari 的使用场景设计。

部署完成后：

1. 使用 iPhone Safari 打开项目网址
2. 点击底部「分享」
3. 选择「添加到主屏幕」
4. 之后可以像普通 App 一样直接打开

⸻

🖼️ 图片获取

项目目前通过第三方开放的数据获取方式读取 X 用户公开时间线中的内容。

当前版本不要求用户提供：

* X 登录密码
* X Cookie
* X 账号授权
* X API Key

注意

X 的页面结构、反爬机制以及第三方数据节点都可能发生变化。

因此：

本项目不能保证所有 X 用户、所有时间段以及所有情况下都能正常获取数据。

如果数据节点出现限流、失效或者无法访问，可能导致图片无法加载。

⸻

⬇️ 原图下载

点击图片后，程序会优先尝试获取对应图片的较高质量版本。

如果服务器无法获取原图：

* 可以尝试重新加载
* 可以打开对应 X 原帖
* 可以在 X 中自行保存图片

实际能够获取到的图片质量取决于 X 原始媒体以及当前数据获取节点。

🚀 部署

本项目可以部署到支持 Docker 的云服务器。

当前项目包含：

x-v1/
├── app.py
├── Dockerfile
├── render.yaml
├── requirements.txt
├── README.md
└── static/

使用 Render 部署

1. 将项目上传到 GitHub
2. 创建 Render Web Service
3. 连接本 GitHub Repository
4. Render 根据 Dockerfile 自动构建
5. 等待部署完成
6. 使用 Render 提供的网址访问

项目同时提供了 render.yaml，方便进行部署配置。

用于构建项目运行环境。

render.yaml

requirements.txt

Python 项目依赖。

⚠️ 当前版本限制

1. 数据获取存在不稳定性

第三方数据节点可能出现：

* 限流
* Cloudflare 拦截
* 节点失效
* 网络异常
* X 页面结构变化

因此某些情况下可能无法获取图片。

2. 历史数据并非无限

当前版本主要针对个人低频使用场景设计。

一次请求不会无限制扫描一个博主的全部历史帖子。

这样可以避免一次请求消耗过多服务器资源。

3. 私密账号

本项目主要针对 X 的公开内容。

无法保证能够获取：

* 私密账号
* 仅登录用户可见的内容
* 已删除内容
* 受访问权限限制的内容

⸻

🔐 安全注意事项

不要将以下信息上传到 GitHub：

X 密码
X Cookie
API Key
数据库密码
服务器密钥
个人访问 Token

如果以后需要加入 API Key、数据库或者用户登录功能，应当使用服务器环境变量保存敏感信息，而不是直接写进源代码。
